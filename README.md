# 📞 Landline Phone Audio & AI Gateway for macOS

โปรเจกต์เปลี่ยนโทรศัพท์บ้านเก่าหัว RJ11 ที่ต่อเข้าอุปกรณ์ **Planet VoIP Gateway (FXS ATA)** ให้กลายเป็น **ไมโครโฟนและหูฟังไร้สาย/มีสายสำหรับ Mac** (Zero STT, Direct Audio) หรือจะเลือกใช้งานเป็น **ไมค์พิมพ์ข้อความ AI (Dictation)** ลงตำแหน่งเคอร์เซอร์บน Mac ได้ตามต้องการ

---

## 🎛️ โหมดการทำงาน (Operation Modes)

ระบบรองรับ 2 โหมดการทำงาน (เลือกได้ในไฟล์ `config.py` หรือ `.env`):

### 1. โหมดหูฟังและไมโครโฟนเต็มตัว (`OPERATION_MODE=audio_bridge`) — *[โหมดปัจจุบัน]*
* **🎙️ ไมโครโฟน (พูดใส่หูโทรศัพท์):** สัญญาณเสียงจากไมค์หูโทรศัพท์จะถูกสตรีมสดเข้าอุปกรณ์ไมค์ของ Mac (`Microsoft Teams Audio`) แบบ Real-time 0 latency
* **🎧 ลำโพงหูฟัง (ฟังเสียงจาก Mac ผ่านหูโทรศัพท์):** สัญญาณเสียงใดๆ ที่ส่งออกทาง `BlackHole 2ch` จะถูกสตรีมสดเข้าไปดังในลำโพงหูโทรศัพท์บ้านทันที
* **ไม่มีการแปลงตัวหนังสือ:** ปิด Whisper, ปิด AI, ปิดการพิมพ์หน้าจอทั้งหมด
* **ใช้ได้กับทุกโปรแกรม (Full-Duplex):** ใน **Zoom, Google Meet, Discord, YouTube, QuickTime, Voice Memos**:
  * **Microphone (Input):** เลือก **`Microsoft Teams Audio`** *(พูดใส่หูโทรศัพท์)*
  * **Speaker (Output):** เลือก **`BlackHole 2ch`** *(เสียงจากคอม/คู่สนทนาจะมาดังในหูโทรศัพท์)*

### 2. โหมดไมค์พิมพ์งาน AI (`OPERATION_MODE=ai_dictation`)
* ใช้ Whisper ถอดเสียงภาษาไทย พร้อมระบบ Refinement เรียบเรียงคำ และพิมพ์ลงหน้าจอเคอร์เซอร์อัตโนมัติ

## 📞 ขั้นตอนการใช้งานจริงในชีวิตประจำวัน

1. **เตรียมหน้าจอ**: คลิกวางเคอร์เซอร์ไว้ในโปรแกรมที่ต้องการพิมพ์ข้อความ (เช่น Notes, Word, Pages, Claude, Gemini, หรือแชท) ให้เคอร์เซอร์กะพริบอยู่
2. **ยกหูโทรศัพท์บ้านขึ้นมา (Off-hook)**:
   - ระบบ Hotline ของ Planet จะโทรเข้ามาที่ Mac อัตโนมัติใน 1 วินาที
   - จะได้ยินเสียงสัญญาณเชื่อมต่อ **Chime (ติ๊ง-ต่อง)** ในหูโทรศัพท์ แปลว่าเชื่อมต่อกับ Mac พร้อมรับคำพูดแล้ว
3. **พูดข้อความลงไปในหูโทรศัพท์**:
   - สามารถพูดภาษาไทยหรือภาษาอังกฤษได้ตามปกติ
4. **เมื่อพูดจบ (เว้นจังหวะ 1-2 วินาที)**:
   - ข้อความจะถูกพิมพ์ลงตำแหน่งเคอร์เซอร์บน Mac **ทันที 1 ครั้ง** พร้อมเคาะเว้นวรรคท้ายประโยคให้อัตโนมัติ
   - จะได้ยินเสียง Chime ดนตรีนุ่มๆ เพราะๆ (Marimba 2 โน้ต C5->E5 นุ่มหู ไม่แสบแก้วหู) แจ้งเตือนว่าพิมพ์เสร็จแล้วและพร้อมรับประโยคถัดไปทันที
   - *หมายเหตุ: หากเป็นคำถาม เช่น "ตอนนี้กี่โมงแล้ว" หรือใช้งานร่วมกับ Gemini API ระบบจะตอบคำตอบสั้นๆ ให้ฟังผ่านหูโทรศัพท์*
5. **วางหูโทรศัพท์กลับลงแท่น (On-hook)**: ระบบจะตัดสายอัตโนมัติ

## 🧠 สมองกล Antigravity AI (Auto-Correction & Refinement)
โปรเจกต์นี้เชื่อมต่อกับ **Antigravity Agent API ภายในเครื่องโดยตรง** (ไม่จำเป็นต้องต่อ API Key ภายนอก):
- เมื่อ Whisper ถอดเสียงดิบออกมา (ซึ่งอาจมีคำเพี้ยนตามย่านความถี่เสียงโทรศัพท์ เช่น *"กดสอบพิมเค้าความ"*, *"โทรเศษบานเกา"*)
- สัญญาณข้อความจะถูกส่งต่อไปให้ **Antigravity** วิเคราะห์เสียงสัทศาสตร์และบริบทของประโยคทันที
- Antigravity จะเรียบเรียงคำที่ถูกต้อง (เช่น *"ทดสอบพิมพ์ข้อความ"*, *"โทรศัพท์บ้านเก่า"*) ก่อนจะนำไป Paste ลงบนหน้าจอของผู้ใช้
- ทำงานรวดเร็วใน ~1 วินาที และใช้งานได้ฟรีโดยตรงผ่านสภาพแวดล้อม Antigravity ในเครื่อง

## ⚙️ การตั้งค่าเพิ่มเติม (Configuration)

### 1. การใส่ Gemini API Key (ตัวเลือกเสริมสำหรับถาม-ตอบ AI)
หากต้องการให้ AI คิดคำตอบเชิงลึกหรือตอบคำถามผ่านหูโทรศัพท์ ให้แก้ไขไฟล์ `.env`:
```bash
nano /Users/litarcopperkaikem/Documents/Repositiry/phone-ai-gateway/.env
```
เพิ่มหรือแก้ไขบรรทัด:
```ini
GEMINI_API_KEY=AIzaSy...
```

### 2. การปรับแต่งเสียงสัญญาณพร้อมใช้งาน (Ready Tone Settings)
สามารถเลือกสไตล์เสียงแจ้งเตือนพร้อมพิมพ์และปรับความดังได้ตามต้องการในไฟล์ `.env` หรือ `config.py`:
- `READY_TONE_STYLE`: 
  - `chime` (ค่าเริ่มต้น): เสียง Chime มาริมบา 2 โน้ตไล่เสียงขึ้น นุ่มหู ฟังสบาย
  - `droplet`: เสียงหยดน้ำ / ฟองสบู่นุ่มๆ (Water Pop)
  - `bell`: เสียงกระดิ่ง Fender Rhodes กังวานนุ่ม
- `READY_TONE_VOLUME`: ระดับความดัง (ค่าเริ่มต้น `4200` ฟังสบายพอดีหู ไม่แสบแก้วหู)

### 3. การอนุญาตสิทธิ์ Accessibility บน macOS
เพื่อให้ macOS ยอมให้สคริปต์สั่งพิมพ์ข้อความลงเคอร์เซอร์ของโปรแกรมอื่นได้:
- ไปที่ **System Settings** > **Privacy & Security** > **Accessibility**
- ตรวจสอบว่ามี **Terminal** หรือ **Python** ได้รับการติ๊กอนุญาต (ON)

## 🔌 วิธีต่อสายแลนตรงจากกล่องเข้า Mac (Direct Peer-to-Peer ไม่ผ่านเร้าเตอร์)

หากไม่ต้องการต่อกล่องเข้าเร้าเตอร์บ้าน สามารถเอาสายแลนเสียบตรงระหว่างกล่อง Planet กับพอร์ตแลนของ Mac ได้เลย:
1. เสียบสายแลนจากช่อง **WAN/LAN** ของกล่อง Planet VIP-157S เข้าพอร์ต **Ethernet** ของ Mac (ใช้สายแลนธรรมดาได้เลย มีระบบ Auto-MDIX ในตัว)
2. บน Mac ไปที่ **System Settings** > **Network** > เลือก **Ethernet**
3. ตรง **Configure IPv4** เปลี่ยนเป็น **Manually**:
   - **IP Address:** `192.168.1.17`
   - **Subnet Mask:** `255.255.255.0`
   - **Router:** *เว้นว่างไว้ ไม่ต้องกรอก* (เพื่อให้ Mac ออกเน็ตผ่าน Wi-Fi ตามปกติ)
4. กด **Apply**: ระบบจะสื่อสารแบบ Peer-to-Peer 1-to-1 สัญญาณเสียงเสถียรสูงสุด ไม่รบกวนเน็ตบ้าน และ Mac ยังต่อ Wi-Fi ท่องเว็บได้ตามปกติ
